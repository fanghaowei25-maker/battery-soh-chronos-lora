# 基于 Chronos-2 与低秩微调的动力电池健康状态预测

本项目探索利用完整放电电压曲线估计磷酸铁锂电池健康状态（State of Health，SOH），形成了数据预处理、模型训练、跨电芯评估和结果复算流程。项目面向工程机械动力电池定期检测场景开展研究，公开数据实验使用 SIT 50 Ah 电芯数据；命题方 242 Ah 电芯的独立验证尚未完成。

## 方法

完整放电电压曲线 → 重采样为 1,024 点 → Chronos-2 编码器 → SOH 回归头。

Chronos-2 是预训练时序基础模型。编码器将电压序列转换为可供回归使用的特征；训练时冻结预训练原权重，在注意力与多层感知器投影中加入低秩微调（LoRA）参数，再由 SOH 回归头输出容量型健康状态。

| 配置 | 主实验设置 |
|---|---|
| 输入 | 单循环完整放电电压曲线，1,024 点 |
| 预训练模型 | `amazon/chronos-2` |
| 低秩微调 | 注意力 q/k/v/o 与 MLP wi/wo；r=8，alpha=16 |
| 回归头 | 层归一化（LayerNorm）与 MLP，隐藏层维度 256、64 |
| 训练标签 | 平滑放电容量 / 50 Ah，即 SOH_rated |
| 学习率 | LoRA：1e-4；回归头：1e-3 |
| 训练轮次 | 最多 20 轮，按验证电芯表现早停与选权重 |
| 评估 | 留一电芯测试（LOCO）；20 电芯 × 3 随机种子，共 60 次独立训练 |
| 初始化 | 每折、每种子恢复初始权重 |
| 集成 | 对三个种子的逐样本预测取平均 |

## 实验结果与口径

MAE 以百分点（pp）表示。下列公开数据结果不能直接视为 242 Ah 命题电芯的性能。

| 分析 | 结果 | 解释 |
|---|---:|---|
| 基础 LoRA + SOH 回归头主实验 | **3.6718 pp** | 全 20 电芯；SOH_rated ≥ 0.7；三种子集成；先计算各电芯 MAE，再对电芯等权平均 |
| 冻结编码器、仅训练回归头对照 | 5.2717 pp | 项目现有对照记录；比较时需同时核对配置和样本范围 |
| 初始容量标定辅助分析：电芯等权 MAE | 2.9992 pp | 初始容量口径；排除三只数据说明标记的异常衰减电芯与三个不完整循环 |
| 初始容量标定辅助分析：池化 MAE | 2.9743 pp | 与上一行同一辅助分析，但对所有合格循环汇总计算 |

辅助分析以每只电芯首五次实测放电容量的最大值作为初始容量基准，将既有预测与参考值换算到该基准下评分。它使用额外的容量标定信息，并改变了评价分母和样本范围；没有重新训练，也不是独立的目标电芯达标实验。上述辅助结果应与主实验结果一同解释。

主实验的逐电芯误差存在明显差异，低 SOH 区间仍是改进重点。历史跨折累积权重实验不用于独立泛化性能结论。

## 复现状态

现有交付包提供训练代码、预处理数据、嵌入缓存、保存的预测和指标复算脚本。各折训练后的最佳权重未归档，因此可以复算已有结果并重新训练，暂不支持直接加载已训练模型开展推理。

现有源代码目录的复训配置为：

```bash
python backbone_adapt.py \
  --out results/reproduction \
  --arms lora \
  --lora-preset all \
  --lr-back 1e-4 \
  --lr-head 1e-3 \
  --seeds 3 \
  --epochs 20 \
  --device cuda:0
```

执行前须安装 CUDA 对应的 PyTorch、chronos-forecasting、NumPy、pandas 和 scikit-learn，并按源代码说明放置数据、嵌入缓存与一致的预训练权重。正式发布版本应补齐依赖版本锁定、路径参数化和从原始数据到评分的完整操作说明。此命令来自现有交付说明，本次未重新启动训练验证。
